## 守ってほしいルール

- 1つの Issue につき、1つのブランチ、1つの PR にする
- PR の本文には必ず `Closes #<Issue番号>` を書く（マージすると Issue が自動で閉じるため）
- PR の本文には次の3つを書く
  1. 何を変えたか（箇条書きで、専門用語なしで）
  2. どうやって確認すればいいか（持ち主が自分で確かめられる手順）
  3. 迷ったところ、決めきれなかったところ
- 依頼があいまいなときは、推測で作業しない。Issue に質問をコメントして止まる
- 頼まれていない変更（ついでの整理や見た目の変更）はしない
- main ブランチに直接 push しない
